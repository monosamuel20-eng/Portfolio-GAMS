# Efficient Frontier Visualisation — Python

A Python notebook that plots the efficient frontier for a multi-asset portfolio, calculates Sharpe ratios, identifies the optimal (maximum Sharpe) portfolio, and draws the Capital Market Line.

---

## What this project does

Portfolio risk-return data (exported from a GAMS optimisation run) is loaded into pandas, plotted as an efficient frontier curve, colour-coded by Sharpe ratio, and annotated with the Capital Market Line. The result is a clean, publication-ready chart showing where on the risk-return trade-off the investor's capital allocation should sit.

---

## Tools

- **Python 3.x**
- `pandas` — data loading and column computation
- `matplotlib` — frontier curve, scatter plot, CML line
- Input: `EF (1).xlsx` — risk and return values per frontier point

---

## Workflow

### Step 1 — Load frontier data
```python
df = pd.read_excel("EF (1).xlsx", usecols="A:C")
# Columns: Risk (portfolio standard deviation), Return (expected return)
```

### Step 2 — Basic frontier curve
Plot Risk on the x-axis and Return on the y-axis as a connected line to confirm the shape of the frontier.

### Step 3 — Sharpe ratio coloring
```python
df["Sharpe"] = df["Return"] / df["Risk"]
# Risk-free rate = 0 (simplified baseline)
```
Re-plot the frontier as a scatter with each point colour-coded by its Sharpe ratio using the `viridis` colormap.

### Step 4 — Identify the optimal portfolio
```python
opt = df.loc[df["Sharpe"].idxmax()]
```
The point with the highest Sharpe ratio is the tangency portfolio — the one a mean-variance investor should hold when they can also allocate to the risk-free asset.

### Step 5 — Capital Market Line
```python
cml_x = [0, max_risk]
cml_y = [rf, rf + opt_sharpe * max_risk]
plt.plot(cml_x, cml_y, color="red", linewidth=2, label="Capital Market Line")
```
The CML connects the risk-free rate (x=0) to the tangency portfolio and extends outward — any point on this line is achievable by mixing the tangency portfolio with the risk-free asset.

---

## Key concepts illustrated

| Concept | Description |
|---|---|
| Efficient Frontier | The set of portfolios that maximise return for a given level of risk |
| Sharpe Ratio | Return per unit of risk (risk-free rate = 0 here) |
| Tangency Portfolio | The frontier point with the highest Sharpe ratio |
| Capital Market Line | The optimal risk-return combinations when a risk-free asset is available |
